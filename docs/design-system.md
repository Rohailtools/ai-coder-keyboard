# Design System: AI Coder Keyboard (Dark-First)

## 1. Colors (Material 3 Dark)
- Primary: #D0BCFF (Material 3 Purple)
- Surface: #1C1B1F
- Surface Variant: #49454F
- On Surface: #E6E1E5
- Accent (Agent): #938F99

## 2. Typography
- Standard: Roboto (Sans-Serif)
- Code: JetBrains Mono (or similar monospace)

## 3. Spacing (4dp Base)
- Small: 4dp
- Standard: 8dp
- Medium: 16dp
- Large: 32dp

## 4. Components
- Keyboard Keys: 48dp minimum touch target
- Floating Overlay: 16dp rounded corners, semi-transparent background (#1C1B1F with 90% alpha)

## 5. Guidelines
- Dark-first, high contrast
- WCAG AA compliant
- 60fps animations
